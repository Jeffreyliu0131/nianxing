# ADR-003：账号隔离的本地优先云同步

- 状态：已采用
- 日期：2026-08-15

## 决策

浏览器继续先写本地缓存，Sites D1 保存可跨设备恢复的权威副本。服务端只使用平台注入的 `oai-authenticated-user-id` 作为分区键，不信任浏览器提交的用户标识。

云端以单用户状态文档和单调递增 revision 保存数据。任务与灵感带 `updatedAt`；删除操作保留墓碑。客户端遇到 revision 冲突时按条目更新时间和墓碑合并，再基于最新 revision 重试。

## 理由

- 记录入口必须在断网时立即可用。
- 私有 Site 已提供稳定登录身份，无需再维护密码或 OAuth 系统。
- 条目规模较小，按用户保存状态文档可减少往返和事务复杂度；revision 与墓碑仍能防止静默覆盖和删除后复活。
- 服务端按平台身份读写，未来扩大分享范围时仍保持用户数据隔离。

## 代价

- 离线设备长期不联网时只能看到自己的本地副本。
- 状态文档设有大小与条目数量上限；未来出现大规模项目或服务端检索需求时，应迁移到规范化记录表。
- Sites 登录身份在不同 Site 之间使用不同用户 ID，迁移到其他站点需要显式导入导出。
