# ADR-002：模型通过服务端网关接入

- 状态：已采用
- 日期：2026-08-13

## 决策

浏览器只调用产品自己的同域整理端点。Sites Worker 默认使用 `deepseek-v4-flash` 的 JSON Output，并允许通过环境变量替换模型与兼容端点。API Key 仅存放在 Sites 秘密变量中。

## 理由

把 DeepSeek Key 放进 PWA 会被任何安装者读取。独立网关还可以集中控制提示词、输出校验、超时、限流和成本预算。

## 代价

启用 AI 需要在 Sites 中配置 DeepSeek API Key，并承担相应调用费用。未配置时仍可完整使用本地整理，但不会获得更复杂的多条目拆分与语义分类。
